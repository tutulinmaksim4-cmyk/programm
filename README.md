# Проект по Банковским операциям
Этот проект преднозначен для сортировки и фильтрации банковских данных
## Как работает проект
- модуль "masks" (маскировка)
   • get_mask_card_number - Функция маскирует номер банковской карты
   • get_mask_account - Функция которая принимает на вход номер счета и возвращает его маску формате
    **XXXX
- модуль "widget" (виджет)
   • mask_account_card - Принимаем строку с типом и номером/счетом карты
    и возвращаем замаскированную версию
   • get_date - Принимаем строку с датой в исходном формате
     и выводим измененный формат
- модуль "processing" (обработка данных)
   • filter_by_state - Функция фильтрует список словарей по значению ключа state.
   • sort_by_date - Функция сортировки по дате
- **Генераторы**:
    - `filter_by_currency`: Фильтрация транзакций по заданной валюте.
    - `transaction_descriptions`: Получение описания операций.
    - `card_number_generator`: Генерация номеров банковских карт заданного диапазона.

## Декораторы
В проекте реализован модуль `decorators.py`, содержащий декоратор `@log`.

### Логирование (`@log`)
Декоратор автоматически фиксирует результат выполнения функции или возникшую ошибку.
- **Параметры**: Принимает необязательный аргумент `filename`.
- **Куда записывает**:
    - Если `filename` указан — логи сохраняются в этот файл.
    - Если `filename` не указан — логи выводятся в консоль.
- **Формат лога**:
    - Успех: `имя_функции ok`
      - Ошибка: `имя_функции error: тип_ошибки. Inputs: (аргументы)`
- **Пример использования:**
python
from src.decorators import log

@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)  # Запишет "my_function ok" в файл mylog.txt
```
